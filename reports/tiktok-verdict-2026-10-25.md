# TikTok: ограниченная проверка и решение

Вердикт: оставить дополнительным источником. Речь иногда получается быстро и без
аккаунта, но делать её обязательной частью каждого исследования пока не стоит.
Текущая тематическая политика уже включает TikTok только по прямому упоминанию;
модель и планировщик также могут выбрать его явно. Общий веб может найти ролик и
без отдельного запроса по TikTok.

## Метод

Восемь разных публичных роликов из четырёх тематических запросов: Kakadu/AI,
программирование, рецепты, наука. Не обходились профили авторов, не использовались
сохранённые cookies, аккаунты, OCR или API языковой модели. Настроенный гостевой
прокси использовался штатным способом. Это небольшая неслучайная выборка.

Условия: до 25 секунд на источник, до 8 МБ на ограниченный гостевой транспорт
медиа/субтитров, ролик для локального распознавания до 180 секунд, звук до первых
90 секунд. Восемь проверок — отдельный тест; обычный поиск допускает только одно
задание локального распознавания и до двух попыток получения субтитров суммарно
для YouTube/TikTok.

## Исправления, обнаруженные проверкой

- Параметр `writesubtitles` у yt-dlp был выключен по умолчанию. Код установленной
  библиотеки при этом вообще не вызывал извлечение субтитров TikTok. Включено
  `writesubtitles=True`, при сохранении `extract_info(..., download=False)`.
- Проверка релевантности требовала точного совпадения токенов: «рецепт» не совпадал
  с «рецепты», а «готовим» с «готовимдома». Добавлено ограниченное сопоставление
  длинных префиксов; общие токены AI/ИИ сами по себе не разрешают обработку речи.
- Добавлены регрессионные тесты обоих случаев. Всего прошли 126 тестов.

Два пропущенных по релевантности ролика после исправления дошли до проверки
длительности, но не прошли её. Затем повторены все восемь исходных URL с
включённым извлечением субтитров.

результат одного URL показывает нестабильность, а не гарантированный процент успеха.

## Качество и ограничения

Английские расшифровки содержат связные объяснения и технические термины, но также
ошибки. Русская расшифровка Kakadu даёт общий смысл, однако искажает название сервиса,
некоторые слова и формулировки. Точность по эталонной аудиозаписи количественно не
измерялась. Выдавать такие расшифровки за точные цитаты, подтверждения версий моделей
или безошибочные числа нельзя. Часть содержания может существовать только на экране;
по согласованным ограничениям оно не считывается.

Распознавание текста речи не проверяет истинность утверждений автора ролика.
Поисковик должен сохранять ссылку, временные отметки и признаки частичного текста,
а точные факты перепроверять по другим источникам.

Дальнейшую разработку TikTok сейчас ограничиваем исправленными гостевыми методами
и текущими лимитами. При отказе — описание/ссылка с честным статусом, затем продолжение
поиска в других источниках. Лимиты не увеличивались.
